## Adding new presets

1. Pick a CC0 (or otherwise unrestricted) HDR; 1k resolution is
   sufficient for IBL — `cmgen` downsamples to a 256-cube anyway.
2. Drop the `.hdr` into this directory; filename = preset name.
3. Add a row to the table above with author + source URL.
4. Add the preset key to `packages/runtime-assets/src/presets.ts`
   `IblPreset` enum (single source of truth — both `cmgen` baker
   and runtime resolver consume it).
5. Run `pnpm bake:ibl` to bake; commit the resulting `.ktx`/
   `sh.txt` outputs alongside.

## Why CC0 only

Bundling non-CC0 art into the SDK distribution forces every
downstream Tride consumer to track license obligations
transitively. CC0 makes the SDK boundary clean: anyone shipping a
Tride app inherits zero attribution debt from the default IBL
chain. Custom user-provided HDRs (drag-drop in editor, baked
client-side via `filament-iblprefilter`) are
end-user-licensed and never enter this directory.
